# 阿里云部署配置与成本估算

更新时间：2026-05-10

> 说明：阿里云价格会随地域、可用区、促销、包年包月折扣、是否新购优惠变化。本文按中国大陆常见地域、生产环境稳定配置估算，最终金额以阿里云控制台购买页为准。

## 当前结论

系统量级：日活约 100，FastAPI + Docker，external/internal 分离，文件走 OSS，数据库走 RDS，AI 调阿里云百炼/DashScope。

推荐配置：

| 模块 | 推荐配置 |
|---|---|
| ECS | `ecs.u1-c1m2.2xlarge`，8核16G |
| 部署方式 | external / internal 分开部署时，建议 2 台 ECS |
| RDS | MySQL 8.0，高可用版，2核4G，ESSD PL1 50GB |
| OSS | 标准存储 LRS，私有 Bucket，同地域 |
| 短信服务 | 阿里云短信服务，验证码/通知短信 |
| 大模型 | 阿里云百炼 / DashScope，建议 `qwen-plus` |
| 安全 | WAF 3.0 + 云安全中心，高防 DDoS 暂不买 |
| 可选安全加强 | 云防火墙按量付费或包年包月 |

## 推荐后端参数

如果 external 和 internal 两台 ECS 都连接同一个 RDS：

```env
WEB_CONCURRENCY=4
DB_POOL_SIZE=3
DB_MAX_OVERFLOW=2

AI_HTTP_TIMEOUT=30
AI_MAX_CONCURRENT_REQUESTS=4
AI_REQUEST_QUEUE_TIMEOUT=5
AI_BACKGROUND_MAX_CONCURRENT=2
AI_CRAWL_MAX_CONCURRENT=1

LOG_DB_QUEUE_SIZE=1000
LOG_DB_WORKERS=2
```

RDS 理论最大连接：

```text
2台 ECS * 4 workers * (3 + 2) = 40 个连接
```

不要把 `DB_POOL_SIZE` 和 `DB_MAX_OVERFLOW` 开太大。ECS 8核16G 很宽裕，但 RDS 连接数仍然要控制。

## 成本估算

### 方案 A：推荐生产版，2 台 ECS，不开云防火墙

适合 external/internal 分离部署。

| 项目 | 配置/假设 | 月成本估算 | 年成本估算 |
|---|---|---:|---:|
| ECS 计算资源 | 2 台 `u1-c1m2.2xlarge`，8核16G | ¥1,348 | ¥8,249 起 |
| 公网带宽/EIP | 2 条 5Mbps | ¥250 | ¥3,000 |
| ECS 系统盘 | 2 块 80GB，粗估 | ¥80 | ¥960 |
| RDS MySQL | 高可用版 2核4G，50GB | ¥500 | ¥4,666 起 |
| OSS | 标准 LRS 500GB 存储包 + 少量外网流量 | ¥100 | ¥1,100 |
| 短信服务 | 约 1000 条/月 | ¥45-50 | ¥540-600 |
| 百炼/DashScope | qwen-plus，中低用量 | ¥50-200 | ¥600-2,400 |
| WAF 3.0 | 基础版预算口径 | 约 ¥1,000 | 约 ¥12,000 |
| 云安全中心 | 高级版/防病毒版，2 台 ECS | ¥120-150 | ¥1,440-1,800 |

合计：

```text
月成本：约 ¥3,500 - ¥3,700
年成本：约 ¥33,000 - ¥36,000 起
```

说明：

- 月成本按 ECS 月付目录价估算。
- 年成本按 ECS/RDS 可能有包年折扣估算，所以不是简单的月成本 × 12。
- OSS、短信、AI 是用量型，实际会随访问量和文件量变化。

## 安全配置建议

当前建议优先级：

1. WAF 3.0：建议购买，防 SQL 注入、XSS、WebShell、CC、恶意扫描。
2. 云安全中心：建议购买，高级版或至少防病毒版，用于主机漏洞、病毒、异常登录、入侵检测。
3. 云防火墙：预算允许再加；它很有用，但对 DAU 100 的系统成本占比偏高。
4. DDoS 高防：暂不购买，先使用阿里云默认 DDoS 基础防护。被大流量攻击或业务强依赖连续可用时再加。

低成本但必须做的配置：

- ECS 安全组只开放 `80/443/22`，后端 `8000` 不直接暴露公网。
- RDS 白名单只允许 ECS 内网 IP。
- OSS Bucket 私有读写，使用后端签名 URL，AccessKey 不进前端。
- 短信验证码加频控，防刷短信费用。
- 登录、验证码、AI 聊天接口加 WAF/后端限流。
- 云监控配置告警：ECS CPU/内存/磁盘、RDS CPU/连接数、OSS 流量、短信费用、百炼费用。

## 增加测试服务器时的资源复用建议

如果再增加 2 台测试 ECS，建议测试环境只复用“基础账号级服务”，不要复用生产数据库和生产 OSS Bucket。

### 建议公用

| 资源 | 是否可公用 | 说明 |
|---|---|---|
| 阿里云账号 / RAM 管理 | 可以 | 用 RAM 子账号和权限隔离测试、生产操作权限。 |
| 百炼 / DashScope | 可以 | 使用同一个阿里云服务即可，但建议测试环境单独使用较低成本模型或限额。 |
| 短信服务 | 可以 | 可以共用同一短信服务，但测试环境必须加白名单/低频控，避免误发和刷费用。 |
| 域名体系 | 可以 | 生产用正式域名，测试用 `test.example.com`、`staging.example.com` 子域名。 |
| WAF 实例 | 可以视情况 | 如果 WAF 支持多个域名接入，可以把测试域名也接入；测试环境也可以只做安全组限制。 |
| 云安全中心 | 可以 | 每台 ECS 仍按授权计费，但使用同一个云安全中心控制台管理。 |
| 云监控 / 告警 | 可以 | 告警规则区分生产和测试，测试告警不要打扰生产值班。 |

### 建议隔离

| 资源 | 是否建议隔离 | 原因 |
|---|---|---|
| RDS 数据库 | 必须隔离 | 测试环境必须使用单独 RDS 实例，不能和生产 RDS 共用实例，避免测试迁移、压测、误操作影响生产数据和生产性能。 |
| OSS Bucket | 建议隔离 | 测试上传、删除、清理策略不要影响生产文件。建议单独建 `anti-pro-test` Bucket。 |
| Redis/Tair | 如果以后使用，建议隔离 | session、限流、任务锁不要和生产混用。 |
| AccessKey / 密钥 | 建议隔离 | 测试环境用独立 RAM AK，权限只给测试 Bucket、测试库相关资源。 |
| 日志库 / 审计库 | 建议隔离 | 测试请求和生产审计不要混在一起。 |

### 可以节省的部分

测试环境不需要完全复制生产配置：

| 资源 | 测试环境建议 |
|---|---|
| ECS | 至少 1 台对齐生产 8核16G，第 2 台可以用 2核4G。 |
| RDS | 单独测试 RDS，建议 1核2G 起步；不要共用生产 RDS 实例。 |
| OSS | 单独 Bucket，但不用买大存储包，按量或小存储包即可。 |
| WAF | 可不单独买，测试域名限制 IP 白名单更省。 |
| 云防火墙 | 测试环境一般不需要单独购买。 |
| DDoS 高防 | 测试环境不需要。 |
| CDN | 测试环境不需要。 |
| 短信 | 使用测试白名单手机号，限制频率，避免真实群发。 |
| 百炼/DashScope | 使用同一个服务，但设置测试 API Key、限额和更便宜模型。 |

### 推荐测试环境组合

生产对齐 + 成本克制版：

```text
测试 ECS：2 台
- 1 台对齐生产：u1-c1m2.2xlarge，8核16G
- 1 台轻量测试：2核4G
测试 RDS：单独 1核2G，创建 test_external/test_internal 独立库和独立账号
OSS：单独测试 Bucket，私有读写
短信：共用服务，测试手机号白名单
百炼：共用服务，测试 Key + 用量限额
WAF：不单独买，测试域名加 IP 白名单
云安全中心：覆盖测试 ECS
云防火墙：不买
```

更稳隔离版：

```text
测试 ECS：2 台
- 1 台对齐生产：u1-c1m2.2xlarge，8核16G
- 1 台轻量测试：2核4G
测试 RDS：单独 1核2G；如果要做上线前性能验证，可临时升到 2核4G
测试 OSS：单独 Bucket
短信 / 百炼：共用服务但独立 Key 和限额
WAF：测试域名接入已有 WAF，或只允许公司 IP 访问
云安全中心：覆盖测试 ECS
```

这样做的原因：

```text
8核16G 测试机：用于上线前回归、性能验证、Docker worker/RDS 连接数验证、故障演练。
2核4G 测试机：用于普通功能测试、管理端/内部端验证、开发联调。
```

如果测试环境也要完整模拟 external/internal 两端都 8核16G，可以买 2 台生产同规格测试机，但对当前 DAU 100 来说成本偏高。

### 测试环境配置注意

测试环境 `.env` 必须和生产区分：

```env
DEPLOYMENT_MODE=external 或 internal
DB_NAME=anti_pro_test_external
DB_USER=anti_pro_test_user
OSS_BUCKET_NAME=anti-pro-test
AI_MODEL_NAME=qwen-turbo
RATE_LIMIT_ENABLED=True
LOG_DB_ENABLED=True
```

生产和测试不要共用：

```text
JWT_SECRET_KEY
DB_NAME
DB_USER
OSS_BUCKET_NAME
OSS_ACCESS_KEY_ID / OSS_ACCESS_KEY_SECRET
```

建议测试环境上线策略：

```text
1. 测试环境至少 1 台 ECS 对齐生产 8核16G。
2. 第 2 台测试 ECS 可使用 2核4G 节省成本。
3. 测试数据库使用单独 RDS 实例，不能和生产共用实例。
4. 测试 OSS 单独 Bucket。
5. 测试域名只允许公司/开发人员 IP 访问。
6. 测试短信只允许白名单手机号。
7. 测试百炼设置月度预算告警。
```

## 价格依据与参考

- ECS `ecs.u1-c1m2.2xlarge`：8核16G，目录月价约 ¥673.92/月，年付月价约 ¥343.70/月。参考阿里云开发者社区整理的 u1 价格表。
